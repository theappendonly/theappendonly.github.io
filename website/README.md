# Personal site (GitHub Pages)

- `index.html` — layout. Rarely needs touching.
- `style.css` — colors/fonts (match brand.py).
- `projects.js` — the about text, the links and the 8 tiles. **Edit this to swap a tile.**
- `img/` — square images, 800x800 jpg. `profile.jpg` is placeholder #214.

Swap a tile: drop a square image in `img/`, then change that tile's title / tag / hook / image / url in `projects.js`.
Open `index.html` straight from disk to preview; no server needed.

Publish: create a public repo named exactly `theappendonly.github.io`, push these files to `main`, and the site is live at https://theappendonly.github.io within a minute or two.
